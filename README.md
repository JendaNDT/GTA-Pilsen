# Plzeň naplno – sestavené webové verze

Tato větev obsahuje jen sestavené hry pro GitHub Pages:

- **kořen** – webová verze z enginu Godot (adresář `godot/`, revize d868511 větve `godot/prestavba`),
- **`zkouska-vzhledu/`** – původní webová hra (three.js) s novým světlem, fasádami, stromy,
  podrobnějšími auty, vyhlazenými tramvajemi, hladkým profilem silnic, chodníky s obrubníkem a zaoblenými
  rohy křižovatek z větve `claude/lucid-bohr-y3rlwb`. Původní vzhled pro srovnání zapne adresa
  `zkouska-vzhledu/?vzhled=puvodni`, původní silnice `zkouska-vzhledu/?silnice=puvodni`, chodníky jen
  v textuře `zkouska-vzhledu/?chodniky=0` a ostré rohy `zkouska-vzhledu/?rohy=0`. Popis změn je
  v `docs/vzhledova-zkouska.md`, `docs/auta-a-mhd.md`, `docs/silnice.md`, `docs/chodniky.md` a `docs/rohy.md`.

Zdrojové kódy, návody a seznam zdrojů dat a licencí jsou v uvedených větvích, v souborech
`README.md` (část „Zdroje a licence dat“) a `godot/README.md`. Uvedení zdrojů je také ve hře
v menu **O hře**.
