# E43 · Dvanáct plzeňských dominant

Zpracovat dvanáct míst z autorova seznamu od Jubilejní brány po rozhlednu Chlum. Použít fotografie pro vlastní výtvarné detaily, zachovat skutečné umístění, všechny pohledové strany a střechy. Pro každý celek porovnat stejný pohled z ulice a shora a ověřit funkci na nízké předvolbě. Změny předat společně jako jednu etapu.
