# E29 – Modely vozového parku

Doplnit ke stávající Fabii po jednom vlastním modelu pro sedan, kombi, SUV, dodávku, sportovní kupé a pick-up. Taxík využije sedan a policejní vůz kombi. Zpracovat také zadní a boční pohledy, zachovat světla, odnímatelné díly a pohyblivá kola a prohlédnout vozy přímo ve hře.
