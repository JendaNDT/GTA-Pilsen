# E39 · Model městského trolejbusu

Přepracovat vzhled krátkého zelenobílého trolejbusu. Vypracovat čelo, zadní stěnu, obě bočnice, podběhy a střechu se dvěma sběrači. Propojit dveře a informační panely se stávajícími spoji. Porovnat modely z ulice i shora a ověřit jízdu linkou 49 a rozpočty vykreslování.
